# Testliste für echte Handys (bitte auf mindestens zwei verschiedenen Geräten)

## Start und Profil
- [ ] App startet ohne Absturz, Symbol und Startbild sehen gut aus
- [ ] Profil anlegen: Name, Datum, Zeit, Ort aus der Liste (zum Beispiel Hohenems, Wien, Berlin, Zürich)
- [ ] Aszendent prüfen: 14.03.1985, 14:30, Wien soll 16°56′ Löwe ergeben
- [ ] Hell- und Dunkelmodus, Schrift gut lesbar, nichts abgeschnitten
- [ ] Handy auf Englisch stellen: Oberfläche wechselt auf Englisch (lange Texte bleiben deutsch)

## Täglich
- [ ] „Dein Tag, persönlich“ erscheint, die 7-Tage-Vorschau klappt auf
- [ ] „Mein Tag“ speichern, App schließen, wieder öffnen: Eintrag ist da
- [ ] Serie zählt am nächsten Tag hoch
- [ ] „Tagesimpuls als Bild teilen“ öffnet das Teilen-Menü, Bild ist schön und ohne persönliche Daten

## Mitteilungen
- [ ] Beim ersten Start fragt die App einmal freundlich, danach Systemfrage
- [ ] Am nächsten Morgen um 7 Uhr und abends um 18 Uhr kommt je eine leise Mitteilung
- [ ] Nach Neustart des Handys kommen sie weiter
- [ ] Tipp auf die Mitteilung öffnet die App
- [ ] Bei „Nein danke“ kommt keine Mitteilung und die Frage nie wieder

## Module
- [ ] Alle 14 Module unter Erweiterung öffnen, scrollen, zurück mit der Zurück-Taste des Handys
- [ ] Zurück-Taste: Modul → Menü → Heute → App schließt
- [ ] Tarot: Tageskarte, Legung; Traumdeutung: Suche; Pendel; Mentor: Check-in komplett
- [ ] Partner vergleichen: positive Texte, keine Sterne

## Daten
- [ ] Mehr → Daten sichern → Datei speichern/teilen klappt (zum Beispiel an Drive oder E-Mail)
- [ ] App-Daten löschen, Sicherung zurückspielen: alles wieder da
- [ ] „Profil und alle Daten löschen“ entfernt wirklich alles
- [ ] Flugmodus: alles funktioniert weiter, nur die Ortssuche zeigt „nicht erreichbar“
- [ ] Ortssuche: „Hohenems“ suchen, Treffer antippen, Breite, Länge und Zeitzone werden gefüllt
- [ ] Ortssuche: ein Ort außerhalb von AT/DE/CH/LI/LU/IT zeigt den Hinweis zur manuellen Zeitzone

## Rechtliches
- [ ] Mehr → Rechtliches: Impressum, Datenschutz, Nutzungshinweise, Lizenzen lesbar
- [ ] Spendenknopf öffnet PayPal im Browser mit dem richtigen Betrag
- [ ] Es gibt keinen Hinweis „Prototyp“ mehr
